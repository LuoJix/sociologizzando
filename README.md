# Sociologizzando

Collana di tutorial per fare ricerca sociale con **dati pubblici e strumenti gratuiti**, di Giovanni Martini.

Ogni volume insegna un metodo con un esempio concreto, e mette a disposizione i materiali per rifare ogni passo: programmi in R, fogli elettronici, dati e istruzioni scritte per chi non ha mai programmato.

## I volumi

1. ***Lo sappiamo già*. Misurare le disuguaglianze di salute con dati pubblici e strumenti gratuiti** — in preparazione. I materiali saranno pubblicati qui all'uscita del libro.
